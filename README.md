
## Project info

This is a React web application built to enable animal owners easy access to nearby veterinary care services.
On this app, an animal owner can register, add animals, schedule appointments with vets, access first aid supports and find nearby vet clinics.

## Technologies used for the project

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

This project requires Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

## To edit the code

**Use your preferred IDE**

Follow these steps:

```sh
# Step 1: Clone the repository using the project's Git URL.
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory.
cd <YOUR_PROJECT_NAME>

# Step 3: Install the necessary dependencies.
npm i

# Step 4: Start the development server with auto-reloading and an instant preview.
npm run dev
```
